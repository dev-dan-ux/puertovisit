# Galera Escapes

Tourism website for the Applied Business Tools and Technologies in Tourism final exam.
Built with HTML, CSS, and JavaScript only. Business details are fictional.

## Before you submit
1. Images in `images/` are web photos with credits listed in `gallery.html`. Verify each source and update the credit line, or swap them with your own photos using the same file names (`hero.jpg`, `g1.jpg` to `g8.jpg`).
2. Replace the email and mobile number with your own sample details.
3. Change the sample reviews if your instructor requires real feedback.
